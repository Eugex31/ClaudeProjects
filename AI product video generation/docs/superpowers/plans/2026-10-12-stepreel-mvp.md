# StepReel MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a multi-tenant SaaS where a company uploads a GLB model and its assembly manual, Claude produces a step storyboard, a human edits and approves it, and three.js plays/records an accurate assembly video with a public share link.

**Architecture:** Next.js 16 App Router app at the project root, Supabase for auth/Postgres/Storage with row-level security enforcing tenant isolation, three.js on the client for rendering real geometry. Pure logic (storyboard validation, timeline, manifest, quota, prompt) lives in `lib/` and is unit-tested; Supabase-touching code is tested against a local Supabase stack.

**Tech Stack:** Node 24, Next.js 16, React 19, TypeScript, Tailwind CSS 4, `@supabase/supabase-js` 2.x + `@supabase/ssr`, three.js 0.186, `@anthropic-ai/sdk` 0.133, `zod` 4, `unpdf`, Vitest 5, Playwright 1.64, Supabase CLI 2.x (Docker required).

**Spec:** `docs/superpowers/specs/2026-10-12-manual-to-video-mvp-design.md`

## Global Constraints

- All paths below are relative to `AI product video generation/` (the app root). The git repo root is the parent `ClaudeProjects/`; only `git add` paths inside this folder.
- Languages: `en | pt | es | fr`. Roles: `owner | editor | viewer`. Plans: `pilot | pro`. Project status: `draft | approved`.
- `monthly_generation_quota` default **20**; usage period format `YYYY-MM` (UTC).
- Upload limits: model ≤ **50 MB** `.glb`; manual ≤ **20 MB** `.pdf` or pasted text ≤ **100 KB**; export ≤ **200 MB**.
- Signed URL expiry: **600 s**. Bucket `org-files` (private). Path `{org_id}/{project_id}/{asset_id}-{filename}`.
- Step text limits: title ≤ **60** chars, narration ≤ **300** chars, warning ≤ **200** chars.
- Step duration: `max(4, words / 2.5 + 1.5)` seconds; fly-in **1.5 s** ease-out; offset = direction × **1.5** × largest model dimension.
- Export canvas **1280×720 @ 30 fps**; MIME preference `video/mp4;codecs=avc1` → `video/webm;codecs=vp9` → `video/webm`. Exports have no audio and the UI says so.
- `ANTHROPIC_MODEL` default `claude-sonnet-5-5` (approved in spec). Do not use forced `tool_choice` (400 on this model); use structured outputs (`output_config.format`).
- `SUPABASE_SERVICE_ROLE_KEY` is only imported from `lib/supabase/admin.ts`, which is only imported by server route handlers (share route, generate route usage increment, signup sample seed is SQL).
- Share token: 32 chars, URL-safe random. Invite token: 32 chars. Invite expiry 7 days.
- Next.js 16: request interception file is `proxy.ts` (formerly `middleware.ts`); route `params` are `Promise`s and must be awaited.

## Review Focus

1. **GLB with no named meshes / nested groups** → every mesh still gets a stable id (`part_01`…) that survives reload; tested in Task 4 (`extractManifest` unnamed + nested cases).
2. **Claude returns part ids that don't exist, empty steps, or over-long text** → storyboard is still saved, bad ids dropped and surfaced as issues, never a 500; tested in Task 2 and Task 9.
3. **Editing an approved project** → approval silently resets so an unreviewed video can't be shared; tested in Task 5 (DB trigger) — enforced in SQL, not only UI.
4. **Revoked share link / project returned to draft** → `/v/:token` returns 404, not a stale video; tested in Task 13.
5. **Quota race / Claude failure** → usage not incremented when Claude fails; at-quota org gets 429; tested in Task 9.

`lib/storyboard/validate.ts`:
```ts
import {
  CAMERA_PRESETS, DIRECTIONS, LIMITS,
  type CameraPreset, type Direction, type Issue, type PartManifest, type Step,
} from "./types";

const str = (v: unknown) => (typeof v === "string" ? v.trim() : "");

export function validateStoryboard(raw: unknown[], manifest: PartManifest): { steps: Step[]; issues: Issue[] } {
  const known = new Set(manifest.map((p) => p.id));
  const issues: Issue[] = [];
  const steps: Step[] = [];
  const usedIds = new Set<string>();
  const placedIn = new Map<string, string>();

  raw.forEach((entry, index) => {
    if (!entry || typeof entry !== "object") return;
    const r = entry as Record<string, unknown>;

    let id = str(r.id) || `step_${index + 1}`;
    while (usedIds.has(id)) id = `${id}_${index + 1}`;
    usedIds.add(id);

    const parts: string[] = [];
    for (const p of Array.isArray(r.parts) ? r.parts : []) {
      if (typeof p !== "string") continue;
      if (!known.has(p)) {
        issues.push({ level: "warning", stepId: id, message: `Unknown part "${p}" was removed from this step.` });
        continue;
      }
      if (parts.includes(p)) continue;
      if (placedIn.has(p)) {
        issues.push({ level: "warning", stepId: id, message: `Part "${p}" is placed more than once (first in ${placedIn.get(p)}).` });
      } else {
        placedIn.set(p, id);
      }
      parts.push(p);
    }

    const from = (DIRECTIONS as readonly string[]).includes(r.from as string) ? (r.from as Direction) : "above";
    const camera = (CAMERA_PRESETS as readonly string[]).includes(r.camera as string) ? (r.camera as CameraPreset) : "iso";
    const warning = str(r.warning).slice(0, LIMITS.warning);

    steps.push({
      id,
      title: str(r.title).slice(0, LIMITS.title) || `Step ${steps.length + 1}`,
      narration: str(r.narration).slice(0, LIMITS.narration),
      parts,
      from,
      camera,
      ...(warning ? { warning } : {}),
    });
  });

  if (steps.length === 0) issues.push({ level: "error", message: "The storyboard has no steps." });

  for (const p of manifest) {
    if (!placedIn.has(p.id)) issues.push({ level: "warning", message: `Part "${p.label}" (${p.id}) is never placed in any step.` });
  }
  return { steps, issues };
}
```

`lib/player/timeline.ts`:
```ts
import type { Direction, PartManifest, Step, Vec3 } from "@/lib/storyboard/types";

export const FLY_IN_SECONDS = 1.5;
const WORDS_PER_SECOND = 2.5;

const DIRECTION_VECTORS: Record<Direction, Vec3> = {
  above: [0, 1, 0], below: [0, -1, 0], left: [-1, 0, 0],
  right: [1, 0, 0], front: [0, 0, 1], back: [0, 0, -1],
};

export function stepDuration(narration: string): number {
  const words = narration.trim() ? narration.trim().split(/\s+/).length : 0;
  return Math.max(4, words / WORDS_PER_SECOND + FLY_IN_SECONDS);
}

export type TimelineStep = {
  step: Step; index: number; start: number; duration: number;
  visibleBefore: string[];
  animating: { partId: string; offset: Vec3 }[];
};
export type Timeline = { steps: TimelineStep[]; total: number; extent: number };

export function buildTimeline(steps: Step[], manifest: PartManifest): Timeline {
  const extent = manifest.reduce((m, p) => Math.max(m, ...p.size), 0) || 1;
  const placed: string[] = [];
  let t = 0;
  const out = steps.map((step, index) => {
    const duration = stepDuration(step.narration);
    const v = DIRECTION_VECTORS[step.from];
    const entry: TimelineStep = {
      step, index, start: t, duration,
      visibleBefore: [...placed],
      // "+ 0" turns -0 into 0 so offsets compare cleanly
      animating: step.parts.map((partId) => ({ partId, offset: v.map((c) => c * 1.5 * extent + 0) as Vec3 })),
    };
    for (const p of step.parts) if (!placed.includes(p)) placed.push(p);
    t += duration;
    return entry;
  });
  return { steps: out, total: t, extent };
}

export function locate(timeline: Timeline, t: number): { index: number; local: number } {
  const n = timeline.steps.length;
  if (n === 0) return { index: -1, local: 0 };
  const clamped = Math.min(Math.max(t, 0), timeline.total);
  for (let i = 0; i < n; i++) {
    const s = timeline.steps[i];
    if (clamped < s.start + s.duration) return { index: i, local: clamped - s.start };
  }
  return { index: n - 1, local: timeline.steps[n - 1].duration };
}

export function easeOutCubic(x: number): number {
  const c = Math.min(Math.max(x, 0), 1);
  return 1 - Math.pow(1 - c, 3);
}
```

```ts
export type Bounds = { center: Vec3; radius: number };

const DIRS: Record<CameraPreset, Vec3> = {
  front: [0, 0, 1], back: [0, 0, -1], left: [-1, 0, 0], right: [1, 0, 0],
  top: [0, 1, 0.001], iso: [1, 1, 1],
};

export function cameraPosition(preset: CameraPreset, bounds: Bounds): Vec3 {
  const d = DIRS[preset];
  const len = Math.hypot(...d);
  const dist = bounds.radius * 2.5;
  return [0, 1, 2].map((i) => bounds.center[i] + (d[i] / len) * dist + 0) as Vec3;
}
```

```ts
import * as THREE from "three";
import type { PartManifest, Vec3 } from "@/lib/storyboard/types";

const r4 = (n: number) => Math.round(n * 1e4) / 1e4 + 0;

export function assignPartIds(root: THREE.Object3D): THREE.Mesh[] {
  const meshes: THREE.Mesh[] = [];
  root.traverse((o) => { if ((o as THREE.Mesh).isMesh) meshes.push(o as THREE.Mesh); });
  const seen = new Set<string>();
  let unnamed = 0;
  for (const m of meshes) {
    const base = m.name.trim() || `part_${String(++unnamed).padStart(2, "0")}`;
    let candidate = base;
    let n = 2;
    while (seen.has(candidate)) candidate = `${base}_${n++}`;
    m.name = candidate;
    seen.add(candidate);
  }
  return meshes;
}

export function extractManifest(root: THREE.Object3D): PartManifest {
  root.updateMatrixWorld(true);
  return assignPartIds(root).map((m) => {
    const box = new THREE.Box3().setFromObject(m);
    const size = box.getSize(new THREE.Vector3());
    const center = box.getCenter(new THREE.Vector3());
    return {
      id: m.name,
      label: m.name.replace(/_/g, " "),
      size: [r4(size.x), r4(size.y), r4(size.z)] as Vec3,
      center: [r4(center.x), r4(center.y), r4(center.z)] as Vec3,
    };
  });
}

export function partMeshes(root: THREE.Object3D): Map<string, THREE.Mesh> {
  return new Map(assignPartIds(root).map((m) => [m.name, m]));
}
```

```sql
create or replace function public.stamp_approval()
returns trigger language plpgsql security definer set search_path = '' as $$
begin
  if new.status = 'approved' and old.status is distinct from 'approved' then
    if coalesce((select jsonb_array_length(s.steps) from public.storyboards s where s.project_id = new.id), 0) = 0 then
      raise exception 'Cannot approve a project with no steps';
    end if;
    new.approved_by := coalesce(auth.uid(), new.approved_by);
    new.approved_at := now();
  elsif new.status = 'draft' then
    new.approved_by := null;
    new.approved_at := null;
  end if;
  new.updated_at := now();
  return new;
end $$;

create or replace function public.accept_invite(invite_token text)
returns uuid language plpgsql security definer set search_path = '' as $$
declare inv public.invites;
begin
  select * into inv from public.invites
   where token = invite_token and accepted_at is null and expires_at > now();
  if inv.id is null then raise exception 'Invite is invalid or expired'; end if;
  if lower(inv.email) <> lower((select email from auth.users where id = auth.uid())) then
    raise exception 'This invite was sent to a different email address';
  end if;
  insert into public.memberships (org_id, user_id, role) values (inv.org_id, auth.uid(), inv.role)
    on conflict (org_id, user_id) do nothing;
  update public.invites set accepted_at = now() where id = inv.id;
  return inv.org_id;
end $$;
```

```ts
import { createServerClient } from "@supabase/ssr";
import { NextResponse, type NextRequest } from "next/server";

export async function proxy(request: NextRequest) {
  let response = NextResponse.next({ request });
  const supabase = createServerClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!, {
    cookies: {
      getAll: () => request.cookies.getAll(),
      setAll: (list) => {
        list.forEach(({ name, value }) => request.cookies.set(name, value));
        response = NextResponse.next({ request });
        list.forEach(({ name, value, options }) => response.cookies.set(name, value, options));
      },
    },
  });
  const { data: { user } } = await supabase.auth.getUser();
  if (!user && request.nextUrl.pathname.startsWith("/app")) {
    const url = request.nextUrl.clone();
    url.pathname = "/login";
    url.search = `?next=${encodeURIComponent(request.nextUrl.pathname)}`;
    return NextResponse.redirect(url);
  }
  return response;
}

export const config = { matcher: ["/((?!_next/static|_next/image|favicon.ico|sample/).*)"] };
```

```ts
import "server-only";
import { cookies } from "next/headers";
import { redirect } from "next/navigation";
import { createClient } from "@/lib/supabase/server";

export type Role = "owner" | "editor" | "viewer";
export type OrgSummary = { id: string; name: string; role: Role; plan: string; monthly_generation_quota: number };
export const ORG_COOKIE = "stepreel_org";
export const canEdit = (role: Role) => role === "owner" || role === "editor";

export async function listMyOrgs(): Promise<OrgSummary[]> {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) redirect("/login");
  const { data, error } = await supabase
    .from("memberships")
    .select("role, organizations(id, name, plan, monthly_generation_quota)")
    .eq("user_id", user.id);
  if (error) throw error;
  return (data ?? []).map((m: any) => ({ ...m.organizations, role: m.role }));
}

export async function getCurrentOrg(): Promise<OrgSummary> {
  const orgs = await listMyOrgs();
  if (orgs.length === 0) throw new Error("Your account has no workspace. Contact support.");
  const wanted = (await cookies()).get(ORG_COOKIE)?.value;
  return orgs.find((o) => o.id === wanted) ?? orgs[0];
}
```

```ts
export const MAX_MODEL_BYTES = 50 * 1024 * 1024;
export const MAX_PDF_BYTES = 20 * 1024 * 1024;
export const MAX_PASTED_CHARS = 100_000;
const MAX_STORED_CHARS = 500_000;

export function normalizeManualText(text: string): string {
  return text
    .replace(/\r\n?/g, "\n")
    .replace(/[ \t\f\v]+/g, " ")
    .replace(/ *\n */g, "\n")
    .replace(/\n{3,}/g, "\n\n")
    .trim()
    .slice(0, MAX_STORED_CHARS);
}

export function assetPath(orgId: string, projectId: string, assetId: string, filename: string): string {
  return `${orgId}/${projectId}/${assetId}-${filename.replace(/[^A-Za-z0-9._-]/g, "_")}`;
}
```

```ts
export async function POST(request: Request, { params }: { params: Promise<{ id: string }> }) {

    .select("storage_path, org_id").eq("id", assetId).eq("project_id", id).eq("kind", "manual").single();

    const pdf = await getDocumentProxy(new Uint8Array(await file.arrayBuffer()));
    const result = await extractText(pdf, { mergePages: true });
    text = normalizeManualText(result.text as string);
  } catch {
    return NextResponse.json({ error: "This PDF could not be read. Paste the manual text instead." }, { status: 422 });
  }
  if (!text) {
    return NextResponse.json({ error: "No text found in this PDF (it may be scanned images). Paste the manual text instead." }, { status: 422 });
  }
  const { error: upErr } = await supabase.from("storyboards").update({ manual_text: text }).eq("project_id", id);
  if (upErr) return NextResponse.json({ error: upErr.message }, { status: 403 });
```

```ts
import { z } from "zod";
import { CAMERA_PRESETS, DIRECTIONS, LIMITS, type Language, type PartManifest } from "@/lib/storyboard/types";

export const StoryboardOutputSchema = z.object({
  steps: z.array(z.object({
    title: z.string(),
    narration: z.string(),
    parts: z.array(z.string()),
    from: z.enum(DIRECTIONS),
    camera: z.enum(CAMERA_PRESETS),
    warning: z.string(),
  })),
});

const LANGUAGE_NAMES: Record<Language, string> = { en: "English", pt: "Portuguese", es: "Spanish", fr: "French" };

const SYSTEM = `You turn a product's assembly manual into a storyboard for an animated 3D assembly video.
The video renders the customer's real 3D model, so you must only reference the part ids listed in the part list - never invent parts.
Rules:
- Follow the manual's step order. One storyboard step per manual step; split a manual step only if it installs unrelated groups of parts.
- "parts" lists the part ids that are installed (move into place) during that step. Each part id should be installed in exactly one step.
- Match manual wording (e.g. "dowel", "cam lock", "shelf") to part ids using the ids, labels, sizes and positions given. Positions are the assembled positions in metres; y is up.
- "from" is the direction the parts travel in from (e.g. "above" for parts dropped onto a base, "left" for a left side panel).
- "camera" is the preset angle that best shows the parts being installed; prefer "iso" unless another angle is clearly better.
- "title": at most ${LIMITS.title} characters. "narration": one or two short spoken sentences, at most ${LIMITS.narration} characters, plain words a consumer understands.
- "warning": a short safety note only if the manual gives one for that step (two-person lift, sharp edges, do not overtighten); otherwise "".
- Write title, narration and warning in the requested language.`;

export function buildGenerationPrompt(input: { manualText: string; parts: PartManifest; language: Language }) {
  const partList = input.parts
    .map((p) => `- ${p.id} | label: ${p.label} | size: ${p.size.join(" x ")} | position: ${p.center.join(", ")}`)
    .join("\n");
  const user = `Language for all text: ${LANGUAGE_NAMES[input.language]}

<part_list>
${partList}
</part_list>

<manual>
${input.manualText}
</manual>

Produce the storyboard.`;
  return { system: SYSTEM, user };
}
```

```ts
import Anthropic from "@anthropic-ai/sdk";
import { zodOutputFormat } from "@anthropic-ai/sdk/helpers/zod";
import { buildGenerationPrompt, StoryboardOutputSchema } from "./prompt";
import type { Language, PartManifest } from "@/lib/storyboard/types";

export class GenerationError extends Error {
  constructor(message: string, public status: 422 | 502) {
    super(message);
  }
}

export async function generateSteps(
  input: { manualText: string; parts: PartManifest; language: Language },
  client: Anthropic = new Anthropic(),
): Promise<unknown[]> {
  const { system, user } = buildGenerationPrompt(input);
  const response = await client.messages.parse({
    model: process.env.ANTHROPIC_MODEL || "claude-sonnet-5-5",
    max_tokens: 16000,
    system,
    messages: [{ role: "user", content: user }],
    output_config: { format: zodOutputFormat(StoryboardOutputSchema) },
  });
  if (response.stop_reason === "refusal") {
    throw new GenerationError("The AI declined to process this manual. Edit the manual text or build the storyboard manually.", 422);
  }
  if (response.stop_reason === "max_tokens" || !response.parsed_output) {
    throw new GenerationError("The AI response was incomplete. Try again, or shorten the manual.", 502);
  }
  return response.parsed_output.steps;
}
```

`lib/ai/runGeneration.ts`:
```ts
import { canGenerate } from "@/lib/quota";
import { validateStoryboard } from "@/lib/storyboard/validate";
import type { Issue, Language, PartManifest, Step } from "@/lib/storyboard/types";
import type { Role } from "@/lib/data/orgs";
import { GenerationError } from "./generate";

export type GenerationContext = {
  role: Role; quota: number; used: number; language: Language;
  parts: PartManifest; manualText: string; aiConfigured: boolean;
};
export type GenerationDeps = {
  generate: (i: { manualText: string; parts: PartManifest; language: Language }) => Promise<unknown[]>;
  saveSteps: (steps: Step[]) => Promise<void>;
  incrementUsage: () => Promise<void>;
};
type Result = { status: 200; steps: Step[]; issues: Issue[] } | { status: number; error: string };

export async function runGeneration(ctx: GenerationContext | null, deps: GenerationDeps): Promise<Result> {
  if (!ctx) return { status: 404, error: "Project not found." };
  if (ctx.role === "viewer") return { status: 403, error: "Viewers cannot generate storyboards." };
  if (!ctx.aiConfigured) return { status: 503, error: "AI generation is not configured; you can build the storyboard manually." };
  if (!canGenerate(ctx.used, ctx.quota)) {
    return { status: 429, error: `Your workspace has used all ${ctx.quota} AI generations this month.` };
  }
  if (!ctx.manualText.trim()) return { status: 400, error: "Add the manual text before generating." };

  let raw: unknown[];
  try {
    raw = await deps.generate({ manualText: ctx.manualText, parts: ctx.parts, language: ctx.language });
```

```ts
import * as THREE from "three";
import type { PartManifest, Step, Vec3 } from "@/lib/storyboard/types";
import { buildTimeline, easeOutCubic, FLY_IN_SECONDS, locate, type Timeline } from "@/lib/player/timeline";
import { cameraPosition, type Bounds } from "@/lib/player/camera";
import { partMeshes } from "./manifest";
import { loadGlb } from "./loadGlb";

const HIGHLIGHT = new THREE.Color(0xff8a00);
const CAMERA_EASE_SECONDS = 1;

type PartState = { mesh: THREE.Mesh; basePosition: THREE.Vector3; materials: THREE.MeshStandardMaterial[] };

export class AssemblyScene {
  readonly renderer: THREE.WebGLRenderer;
  private scene = new THREE.Scene();
  private camera = new THREE.PerspectiveCamera(40, 16 / 9, 0.01, 1000);
  private parts = new Map<string, PartState>();
  private bounds: Bounds = { center: [0, 0, 0], radius: 1 };
  private raycaster = new THREE.Raycaster();
  timeline: Timeline = { steps: [], total: 0, extent: 1 };

  constructor(private canvas: HTMLCanvasElement, opts: { preserveDrawingBuffer?: boolean } = {}) {
    this.renderer = new THREE.WebGLRenderer({ canvas, antialias: true, preserveDrawingBuffer: opts.preserveDrawingBuffer });
    this.renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
    this.scene.background = new THREE.Color(0xf4f4f5);
    this.scene.add(new THREE.HemisphereLight(0xffffff, 0x888888, 2.2));
    const sun = new THREE.DirectionalLight(0xffffff, 1.6);
    sun.position.set(3, 5, 4);
    this.scene.add(sun);
  }

  async load(url: string) {
    const root = await loadGlb(url);
    this.scene.add(root);
    root.updateMatrixWorld(true);
    for (const [id, mesh] of partMeshes(root)) {
      const source = Array.isArray(mesh.material) ? mesh.material : [mesh.material];
      const materials = source.map((m) => {
        const std = m instanceof THREE.MeshStandardMaterial ? m.clone() : new THREE.MeshStandardMaterial({ color: (m as any).color ?? 0xcccccc });
        std.transparent = true;
        return std;
      });
      mesh.material = materials.length === 1 ? materials[0] : materials;
      this.parts.set(id, { mesh, basePosition: mesh.position.clone(), materials });
    }
    const sphere = new THREE.Box3().setFromObject(root).getBoundingSphere(new THREE.Sphere());
    this.bounds = { center: sphere.center.toArray() as Vec3, radius: sphere.radius || 1 };
    this.camera.near = this.bounds.radius / 100;
    this.camera.far = this.bounds.radius * 100;
    this.camera.updateProjectionMatrix();
  }

  setStoryboard(steps: Step[], manifest: PartManifest) {
    this.timeline = buildTimeline(steps, manifest);
  }

  resize(width: number, height: number) {
    this.renderer.setSize(width, height, false);
    this.camera.aspect = width / height;
    this.camera.updateProjectionMatrix();
  }

  renderAt(t: number) {
    const { index, local } = locate(this.timeline, t);
    const entry = this.timeline.steps[index];
    const visible = new Set(entry?.visibleBefore ?? []);
    const animating = new Map((entry?.animating ?? []).map((a) => [a.partId, a.offset]));
    const progress = easeOutCubic(local / FLY_IN_SECONDS);
    const glow = Math.max(0, 1 - local / (FLY_IN_SECONDS + 1));

    for (const [id, part] of this.parts) {
      const offset = animating.get(id);
      part.mesh.visible = visible.has(id) || offset !== undefined;
      part.mesh.position.copy(part.basePosition);
      if (offset) part.mesh.position.add(this.worldOffsetToLocal(part.mesh, offset).multiplyScalar(1 - progress));
      this.styleMaterials(part, 1, offset ? glow : 0);
    }

    const prev = this.timeline.steps[index - 1]?.step.camera ?? entry?.step.camera ?? "iso";
    const from = new THREE.Vector3(...cameraPosition(prev, this.bounds));
    const to = new THREE.Vector3(...cameraPosition(entry?.step.camera ?? "iso", this.bounds));
    this.placeCamera(from.lerp(to, easeOutCubic(local / CAMERA_EASE_SECONDS)));
    this.renderer.render(this.scene, this.camera);
  }

  renderStepEnd(index: number, selected: string[]) {
    const placed = new Set<string>();
    this.timeline.steps.slice(0, index + 1).forEach((s) => s.step.parts.forEach((p) => placed.add(p)));
    const sel = new Set(selected);
    for (const [id, part] of this.parts) {
      part.mesh.visible = true;
      part.mesh.position.copy(part.basePosition);
      this.styleMaterials(part, placed.has(id) || sel.has(id) ? 1 : 0.15, sel.has(id) ? 0.8 : 0);
    }
    const preset = this.timeline.steps[index]?.step.camera ?? "iso";
    this.placeCamera(new THREE.Vector3(...cameraPosition(preset, this.bounds)));
    this.renderer.render(this.scene, this.camera);
  }

  pick(clientX: number, clientY: number): string | null {
    const rect = this.canvas.getBoundingClientRect();
    const ndc = new THREE.Vector2(((clientX - rect.left) / rect.width) * 2 - 1, -((clientY - rect.top) / rect.height) * 2 + 1);
    this.raycaster.setFromCamera(ndc, this.camera);
    const meshes = [...this.parts.values()].filter((p) => p.mesh.visible).map((p) => p.mesh);
    const hit = this.raycaster.intersectObjects(meshes, false)[0];
    return hit ? hit.object.name : null;
  }

  dispose() {
    this.renderer.dispose();
    this.parts.forEach((p) => p.materials.forEach((m) => m.dispose()));
  }

  private placeCamera(position: THREE.Vector3) {
    this.camera.position.copy(position);
    this.camera.lookAt(...this.bounds.center);
  }

  private worldOffsetToLocal(mesh: THREE.Mesh, offset: Vec3): THREE.Vector3 {
    const parent = mesh.parent!;
    const worldBase = parent.localToWorld(mesh.position.clone());
    const a = parent.worldToLocal(worldBase.clone());
    const b = parent.worldToLocal(worldBase.add(new THREE.Vector3(...offset)));
    return b.sub(a);
  }

  private styleMaterials(part: PartState, opacity: number, glow: number) {
    for (const m of part.materials) {
      m.opacity = opacity;
      m.depthWrite = opacity === 1;
      m.emissive.copy(HIGHLIGHT).multiplyScalar(glow);
    }
  }
}
```

```tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { AssemblyScene } from "@/lib/three/scene";
import { captionFor } from "@/lib/player/captions";
import { locate } from "@/lib/player/timeline";
import { speak, stopSpeaking } from "@/lib/player/speech";
import type { Language, PartManifest, Step } from "@/lib/storyboard/types";
import { Captions } from "./Captions";

export function Player({ modelUrl, steps, manifest, language }: {
  modelUrl: string; steps: Step[]; manifest: PartManifest; language: Language;
}) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const sceneRef = useRef<AssemblyScene | null>(null);
  const timeRef = useRef(0);
  const [ready, setReady] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [playing, setPlaying] = useState(false);
  const [speed, setSpeed] = useState(1);
  const [index, setIndex] = useState(0);

  useEffect(() => {
    const canvas = canvasRef.current!;
    const scene = new AssemblyScene(canvas);
    sceneRef.current = scene;
    const resize = () => scene.resize(canvas.clientWidth, canvas.clientHeight);
    resize();
    window.addEventListener("resize", resize);
    scene.load(modelUrl)
      .then(() => { scene.setStoryboard(steps, manifest); scene.renderAt(0); setReady(true); })
      .catch(() => setError("The 3D model could not be loaded."));
    return () => { window.removeEventListener("resize", resize); stopSpeaking(); scene.dispose(); };
  }, [modelUrl, steps, manifest]);

  useEffect(() => {
    if (!playing || !ready) return;
    const scene = sceneRef.current!;
    let last = performance.now();
    let lastIndex = -1;
    let raf = 0;
    const tick = (now: number) => {
      timeRef.current = Math.min(timeRef.current + ((now - last) / 1000) * speed, scene.timeline.total);
      last = now;
      scene.renderAt(timeRef.current);
      const { index: i } = locate(scene.timeline, timeRef.current);
      if (i !== lastIndex) {
        lastIndex = i;
        setIndex(i);
        speak(scene.timeline.steps[i]?.step.narration ?? "", language, speed);
      }
      if (timeRef.current >= scene.timeline.total) { setPlaying(false); return; }
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [playing, ready, speed, language]);

  function jump(i: number) {
    const scene = sceneRef.current!;
    const clamped = Math.max(0, Math.min(i, scene.timeline.steps.length - 1));
    timeRef.current = scene.timeline.steps[clamped]?.start ?? 0;
    setIndex(clamped);
    stopSpeaking();
    scene.renderAt(timeRef.current);
    if (playing) speak(scene.timeline.steps[clamped].step.narration, language, speed);
  }

  const caption = ready ? captionFor(sceneRef.current!.timeline, index) : null;
  return (
    <div>
      <div className="relative aspect-video w-full overflow-hidden rounded bg-zinc-100">
        <canvas ref={canvasRef} className="h-full w-full" />
        <Captions caption={caption} />
        {error && <p role="alert" className="absolute inset-0 grid place-items-center text-red-700">{error}</p>}
      </div>
      <div className="mt-2 flex flex-wrap items-center gap-2 text-sm">
        <button disabled={!ready} onClick={() => jump(index - 1)} className="rounded border px-2 py-1">◀ Prev</button>
        <button disabled={!ready} onClick={() => {
          if (timeRef.current >= (sceneRef.current?.timeline.total ?? 0)) timeRef.current = 0;
          if (playing) stopSpeaking();
          setPlaying(!playing);
        }} className="rounded bg-black px-3 py-1 text-white">{playing ? "Pause" : "Play"}</button>
        <button disabled={!ready} onClick={() => jump(index + 1)} className="rounded border px-2 py-1">Next ▶</button>
        <button disabled={!ready} onClick={() => jump(0)} className="rounded border px-2 py-1">Restart</button>
        <label className="ml-auto">Speed{" "}
          <select value={speed} onChange={(e) => setSpeed(Number(e.target.value))} className="rounded border">
            <option value={0.75}>0.75×</option><option value={1}>1×</option><option value={1.25}>1.25×</option>
          </select>
        </label>
      </div>
    </div>
  );
}
```

```ts
import type { Step } from "./types";

export function moveStep(steps: Step[], from: number, to: number): Step[] {
  const next = [...steps];
  const [item] = next.splice(from, 1);
  next.splice(to, 0, item);
  return next;
}

export function togglePart(steps: Step[], index: number, partId: string): Step[] {
  const has = steps[index].parts.includes(partId);
  return steps.map((step, i) => {
    if (i === index) return { ...step, parts: has ? step.parts.filter((p) => p !== partId) : [...step.parts, partId] };
    return has ? step : { ...step, parts: step.parts.filter((p) => p !== partId) };
  });
}

export function addStep(steps: Step[], after: number): Step[] {
  const ids = new Set(steps.map((s) => s.id));
  let n = steps.length + 1;
  while (ids.has(`step_${n}`)) n++;
  const step: Step = { id: `step_${n}`, title: "New step", narration: "", parts: [], from: "above", camera: "iso" };
  const next = [...steps];
  next.splice(after + 1, 0, step);
  return next;
}

export const removeStep = (steps: Step[], index: number) => steps.filter((_, i) => i !== index);
```

```ts
export function resolveSamplePath(storagePath: string): string | null {
  const m = storagePath.match(/^sample:([A-Za-z0-9_-]+\.glb)$/);
  return m ? `/sample/${m[1]}` : null;
}

export async function modelUrlFor(supabase: SupabaseClient, storagePath: string): Promise<string> {
  const sample = resolveSamplePath(storagePath);
  if (sample) return sample;
  const { data, error } = await supabase.storage.from("org-files").createSignedUrl(storagePath, 600);
  if (error || !data) throw new Error("Could not sign model URL");
  return data.signedUrl;
```

```ts
import type { PartManifest, Step } from "@/lib/storyboard/types";
import { AssemblyScene } from "@/lib/three/scene";
import { captionFor } from "./captions";
import { locate } from "./timeline";

const MIME_PREFERENCE = ["video/mp4;codecs=avc1", "video/webm;codecs=vp9", "video/webm"];
const WIDTH = 1280;
const HEIGHT = 720;
const FPS = 30;
const TAIL_SECONDS = 0.5;

export function pickMimeType(isSupported: (t: string) => boolean): string | null {
  return MIME_PREFERENCE.find((t) => isSupported(t)) ?? null;
}

export function wrapText(measure: (s: string) => number, text: string, maxWidth: number): string[] {
  const lines: string[] = [];
  let line = "";
  for (const word of text.split(/\s+/).filter(Boolean)) {
    const candidate = line ? `${line} ${word}` : word;
    if (line && measure(candidate) > maxWidth) { lines.push(line); line = word; } else line = candidate;
  }
  if (line) lines.push(line);
  return lines;
}

function drawCaption(ctx: CanvasRenderingContext2D, caption: NonNullable<ReturnType<typeof captionFor>>) {
  const pad = 32;
  const maxWidth = WIDTH - pad * 2;
  ctx.font = "24px system-ui, sans-serif";
  const narration = wrapText((s) => ctx.measureText(s).width, caption.narration, maxWidth).slice(0, 3);
  const height = 110 + narration.length * 30 + (caption.warning ? 40 : 0);
  const grad = ctx.createLinearGradient(0, HEIGHT - height, 0, HEIGHT);
  grad.addColorStop(0, "rgba(0,0,0,0)");
  grad.addColorStop(0.35, "rgba(0,0,0,0.75)");
  ctx.fillStyle = grad;
  ctx.fillRect(0, HEIGHT - height, WIDTH, height);
  let y = HEIGHT - height + 50;
  ctx.fillStyle = "rgba(255,255,255,0.8)";
  ctx.font = "16px system-ui, sans-serif";
  ctx.fillText(caption.counter.toUpperCase(), pad, y);
  y += 34;
  ctx.fillStyle = "#fff";
  ctx.font = "bold 30px system-ui, sans-serif";
  ctx.fillText(caption.title, pad, y);
  ctx.font = "24px system-ui, sans-serif";
  for (const line of narration) { y += 30; ctx.fillText(line, pad, y); }
  if (caption.warning) {
    y += 36;
    ctx.font = "bold 20px system-ui, sans-serif";
    const text = `⚠ ${caption.warning}`;
    ctx.fillStyle = "#fbbf24";
    ctx.fillRect(pad - 6, y - 22, ctx.measureText(text).width + 12, 30);
    ctx.fillStyle = "#000";
    ctx.fillText(text, pad, y);
  }
}

export async function recordVideo(opts: {
  modelUrl: string; steps: Step[]; manifest: PartManifest; onProgress?: (fraction: number) => void;
}): Promise<{ blob: Blob; mimeType: string }> {
  const mimeType = pickMimeType((t) => MediaRecorder.isTypeSupported(t));
  if (!mimeType) throw new Error("This browser cannot record video. Use a recent Chrome or Edge.");

  const glCanvas = document.createElement("canvas");
  glCanvas.width = WIDTH;
  glCanvas.height = HEIGHT;
  const out = document.createElement("canvas");
  out.width = WIDTH;
  out.height = HEIGHT;
  const ctx = out.getContext("2d")!;

  const scene = new AssemblyScene(glCanvas, { preserveDrawingBuffer: true });
  scene.renderer.setPixelRatio(1);
  scene.resize(WIDTH, HEIGHT);
  await scene.load(opts.modelUrl);
  scene.setStoryboard(opts.steps, opts.manifest);
  const total = scene.timeline.total + TAIL_SECONDS;

  const recorder = new MediaRecorder(out.captureStream(FPS), { mimeType, videoBitsPerSecond: 6_000_000 });
  const chunks: Blob[] = [];
  recorder.ondataavailable = (e) => { if (e.data.size) chunks.push(e.data); };
  const stopped = new Promise<void>((resolve) => { recorder.onstop = () => resolve(); });

  const drawFrame = (t: number) => {
    scene.renderAt(t);
    ctx.drawImage(glCanvas, 0, 0);
    const caption = captionFor(scene.timeline, locate(scene.timeline, t).index);
    if (caption) drawCaption(ctx, caption);
  };

  drawFrame(0);
  recorder.start(1000);
  const startedAt = performance.now();
  await new Promise<void>((resolve) => {
    const tick = () => {
      const t = (performance.now() - startedAt) / 1000;
      drawFrame(Math.min(t, scene.timeline.total));
      opts.onProgress?.(Math.min(t / total, 1));
      if (t >= total) return resolve();
      requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
  });
  recorder.stop();
  await stopped;
  scene.dispose();
  return { blob: new Blob(chunks, { type: mimeType.split(";")[0] }), mimeType };
}
```

```tsx
"use client";
import { useState } from "react";
import { createBrowserSupabase } from "@/lib/supabase/client";
import { recordVideo } from "@/lib/player/record";
import { assetPath } from "@/lib/manual";
import type { PartManifest, Step } from "@/lib/storyboard/types";
import type { EditorProject } from "./Editor";

const MAX_EXPORT_BYTES = 200 * 1024 * 1024;

export function RecordButton({ project, steps, parts, modelUrl, approved, canUpload }: {
  project: EditorProject; steps: Step[]; parts: PartManifest; modelUrl: string; approved: boolean; canUpload: boolean;
}) {
  const [progress, setProgress] = useState<number | null>(null);
  const [note, setNote] = useState<string | null>(null);

  async function record() {
    setNote("Recording in real time — keep this tab visible. The file has captions but no voice.");
    setProgress(0);
    try {
      const { blob, mimeType } = await recordVideo({ modelUrl, steps, manifest: parts, onProgress: setProgress });
      const ext = mimeType.startsWith("video/mp4") ? "mp4" : "webm";
      const filename = `${project.name.replace(/[^A-Za-z0-9_-]+/g, "-")}.${ext}`;
      const url = URL.createObjectURL(blob);
      Object.assign(document.createElement("a"), { href: url, download: filename }).click();
      setTimeout(() => URL.revokeObjectURL(url), 10_000);

      if (canUpload && blob.size <= MAX_EXPORT_BYTES) {
        const supabase = createBrowserSupabase();
        const assetId = crypto.randomUUID();
        const path = assetPath(project.org_id, project.id, assetId, filename);
        const { error } = await supabase.storage.from("org-files").upload(path, blob, { contentType: blob.type });
        if (!error) {
          await supabase.from("assets").insert({ id: assetId, org_id: project.org_id, project_id: project.id, kind: "export", storage_path: path, filename, size_bytes: blob.size });
        }
        setNote(error ? `Downloaded, but saving a copy failed: ${error.message}` : "Downloaded and saved to the workspace.");
      } else {
        setNote("Downloaded.");
      }
    } catch (err) {
      setNote(err instanceof Error ? err.message : "Recording failed.");
    } finally {
      setProgress(null);
    }
  }

  return (
    <>
      <button onClick={record} disabled={!approved || progress !== null} title={approved ? "" : "Approve the storyboard first"}
        className="rounded border px-3 py-1 disabled:opacity-40">
        {progress === null ? "Record video" : `Recording ${Math.round(progress * 100)}%`}
      </button>
      {note && <span className="text-xs text-gray-600">{note}</span>}
    </>
  );
}
```

```ts
import "server-only";
import type { SupabaseClient } from "@supabase/supabase-js";
import { createAdminClient } from "@/lib/supabase/admin";
import { modelUrlFor } from "./assets";
import type { Language, PartManifest, Step } from "@/lib/storyboard/types";

export type SharedProject = { name: string; language: Language; parts: PartManifest; steps: Step[]; modelUrl: string };

export async function loadSharedProject(token: string, admin: SupabaseClient = createAdminClient()): Promise<SharedProject | null> {
  if (!/^[A-Za-z0-9_-]{32}$/.test(token)) return null;
  const { data } = await admin
    .from("projects")
    .select("name, language, status, storyboards(parts, steps), assets(kind, storage_path)")
    .eq("share_token", token).eq("status", "approved").maybeSingle();
  if (!data) return null;
  const sb = Array.isArray(data.storyboards) ? data.storyboards[0] : data.storyboards;
  const model = (data.assets as { kind: string; storage_path: string }[]).find((a) => a.kind === "model");
  if (!sb || !model) return null;
  return { name: data.name, language: data.language, parts: sb.parts, steps: sb.steps, modelUrl: await modelUrlFor(admin, model.storage_path) };
}
```

```ts
import { createClient } from "@/lib/supabase/server";
import { randomToken } from "@/lib/tokens";

export async function createShareLink(projectId: string): Promise<string> {
  const supabase = await createClient();
  const { data: p } = await supabase.from("projects").select("status, share_token").eq("id", projectId).single();
  if (!p) throw new Error("Project not found");
  if (p.status !== "approved") throw new Error("Approve the storyboard before sharing");
  if (p.share_token) return p.share_token;
  const token = randomToken();
  const { error } = await supabase.from("projects").update({ share_token: token }).eq("id", projectId);
  if (error) throw new Error(error.message);
  return token;
}

export async function revokeShareLink(projectId: string): Promise<void> {
  const supabase = await createClient();
  const { error } = await supabase.from("projects").update({ share_token: null }).eq("id", projectId);
  if (error) throw new Error(error.message);
}
```

```ts
import * as THREE from "three";

const W = 0.8, H = 1.2, D = 0.3, T = 0.018;
const wood = () => new THREE.MeshStandardMaterial({ color: 0xc8a27a, roughness: 0.8 });
const metal = () => new THREE.MeshStandardMaterial({ color: 0x9ca3af, metalness: 0.8, roughness: 0.3 });
const board = () => new THREE.MeshStandardMaterial({ color: 0xf5f5f4, roughness: 0.9 });

function mesh(name: string, geometry: THREE.BufferGeometry, material: THREE.Material, x: number, y: number, z: number) {
  const m = new THREE.Mesh(geometry, material);
  m.name = name;
  m.position.set(x, y, z);
  return m;
}

export function buildBookshelf(): THREE.Group {
  const g = new THREE.Group();
  g.name = "bookshelf";
  const inner = W - 2 * T;
  const yBottom = 0.05, yTop = H - T / 2;

  g.add(mesh("side_left", new THREE.BoxGeometry(T, H, D), wood(), -(W - T) / 2, H / 2, 0));
  g.add(mesh("side_right", new THREE.BoxGeometry(T, H, D), wood(), (W - T) / 2, H / 2, 0));
  g.add(mesh("bottom", new THREE.BoxGeometry(inner, T, D), wood(), 0, yBottom, 0));
  g.add(mesh("top", new THREE.BoxGeometry(inner, T, D), wood(), 0, yTop, 0));
  [0.33, 0.62, 0.91].forEach((y, i) => g.add(mesh(`shelf_${i + 1}`, new THREE.BoxGeometry(inner, T, D - 0.02), wood(), 0, y, 0.01)));
  g.add(mesh("back_panel", new THREE.BoxGeometry(W, H, 0.004), board(), 0, H / 2, -D / 2 - 0.002));

  let dowel = 0, cam = 0;
  for (const y of [yBottom, yTop]) {
    for (const side of [-1, 1]) {
      for (const z of [-0.1, 0.1]) {
        const d = mesh(`dowel_${++dowel}`, new THREE.CylinderGeometry(0.004, 0.004, 0.03, 12), metal(), side * (inner / 2 - 0.005), y, z);
        d.rotation.z = Math.PI / 2;
        g.add(d);
        g.add(mesh(`cam_lock_${++cam}`, new THREE.CylinderGeometry(0.0075, 0.0075, 0.012, 16), metal(), side * (inner / 2 - 0.035), y + T / 2, z + 0.03));
      }
    }
  }
  return g;
}
```

```ts
import { mkdirSync, writeFileSync } from "node:fs";
import { GLTFExporter } from "three/examples/jsm/exporters/GLTFExporter.js";
import { buildBookshelf } from "../lib/sample/bookshelf";
import { SAMPLE_MANUAL, SAMPLE_PROJECT_NAME, SAMPLE_STEPS } from "../lib/sample/storyboard";
import { extractManifest } from "../lib/three/manifest";

// GLTFExporter uses FileReader to turn Blobs into ArrayBuffers; Node has Blob but no FileReader.
class NodeFileReader {
  result: ArrayBuffer | string | null = null;
  onloadend: (() => void) | null = null;
  readAsArrayBuffer(blob: Blob) { blob.arrayBuffer().then((b) => { this.result = b; this.onloadend?.(); }); }
  readAsDataURL(blob: Blob) {
    blob.arrayBuffer().then((b) => {
      this.result = `data:${blob.type || "application/octet-stream"};base64,${Buffer.from(b).toString("base64")}`;
      this.onloadend?.();
    });
  }
}
(globalThis as any).FileReader ??= NodeFileReader;

async function main() {
  const shelf = buildBookshelf();
  const parts = extractManifest(shelf);
  const glb = (await new GLTFExporter().parseAsync(shelf, { binary: true })) as ArrayBuffer;

  mkdirSync("public/sample", { recursive: true });
  writeFileSync("public/sample/bookshelf.glb", Buffer.from(glb));
  writeFileSync("public/sample/bookshelf-manual.txt", SAMPLE_MANUAL);

  const json = (v: unknown) => `$json$${JSON.stringify(v)}$json$::jsonb`;
  const sql = `-- Generated by \`npm run build:sample\`. Do not edit by hand.
insert into public.sample_templates (id, project_name, manual_text, parts, steps, model_path)
values ('bookshelf', $name$${SAMPLE_PROJECT_NAME}$name$, $manual$${SAMPLE_MANUAL}$manual$, ${json(parts)}, ${json(SAMPLE_STEPS)}, 'bookshelf.glb')
on conflict (id) do update set project_name = excluded.project_name, manual_text = excluded.manual_text,
  parts = excluded.parts, steps = excluded.steps, model_path = excluded.model_path;
`;
  writeFileSync("supabase/migrations/0004_sample_template.sql", sql);
  console.log(`Wrote bookshelf.glb (${glb.byteLength} bytes, ${parts.length} parts) and 0004_sample_template.sql`);
}

main().catch((e) => { console.error(e); process.exit(1); });
```
